# n8s-admin Agent — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy `multica-agent-n8s-admin` — a Multica Claude agent with `kubectl` and `helm` in its container image and a dedicated `cluster-admin` ServiceAccount — and update the Kubernetes Administrator agent definition in Multica with full cluster and GitOps context.

**Architecture:** Four components across three repos. The image update triggers CI automatically on push. Helm chart changes (serviceAccount flexibility + RBAC template) land in `helm-multica`. The `n8s-admin` agent instance is defined only in `gitops-argo` values (not in chart defaults). ArgoCD auto-syncs on push. The Multica API update is a direct API call using a PAT from OpenBao.

**Tech Stack:** Docker, Helm 3, Kubernetes RBAC, ArgoCD GitOps, OpenBao (`bao` CLI), Multica REST API, `gh` CLI, `curl`, `jq`

### Task 3: Add agent RBAC template

- [ ] **Step 1: Create the template file**

Create `/home/nate/code/helm-multica/multica/templates/agent-rbac.yaml` with this content:

```yaml
{{- range $name, $agent := .Values.agents }}
{{- if and $agent.enabled $agent.serviceAccount $agent.serviceAccount.create }}
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: {{ $agent.serviceAccount.name }}
  namespace: {{ $.Release.Namespace }}
  labels:
    {{- include "multica.labels" $ | nindent 4 }}
    app.kubernetes.io/component: agent
{{- if $agent.serviceAccount.clusterRoleBinding }}
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: {{ $agent.serviceAccount.name }}
  labels:
    {{- include "multica.labels" $ | nindent 4 }}
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: {{ $agent.serviceAccount.clusterRoleBinding.clusterRole }}
subjects:
  - kind: ServiceAccount
    name: {{ $agent.serviceAccount.name }}
    namespace: {{ $.Release.Namespace }}
{{- end }}
{{- end }}
{{- end }}
```
